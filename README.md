# train-booking-python-full-stack
A clean, responsive 3-page web app built with HTML, CSS, JS and python backend integration. Features Tamil Nadu route selection, travel date picker and animated train banner.

---

## 🎯 Objective

To design and develop a responsive and user-friendly train ticket booking web application using HTML, CSS, and Python  that allows users to:

- Select From and To District

- Enter passenger details.

- Choose available train routes.

- Book tickets with a confirmation message.

  ---

## ⚙️ Procedure

1. UI Design:

- Designed a clean, mobile-responsive interface using HTML and CSS.

- Added a modern train illustration and step progress indicators for navigation.

2. Frontend Setup:

- Created three pages in a single index.html using JavaScript-based navigation Booking → Passenger → Route


3. Backend Setup (Flask):

- Used Flask to handle book route for booking confirmation.

- Connected the frontend and backend through fetch() API calls.

4. Testing:

- Tested on different screen sizes for responsive UI.

- Verified backend responses and validation alerts.

## 🪜 Step-Wise Execution

| Step No | Task             | Description                                       |
| ------- | ---------------- | ------------------------------------------------- |
| 1       | Create Folder    | Make project folder with `/templates` subfolder   |
| 2       | Add `index.html` | Place HTML UI file in `/templates`                |

| 4       | Add Image        | Store your train image in `/static/images/`       |
| 5       | Run Flask App    | Run using `python app.py`                         |

| 7       | Test Booking     | Check the 3-step booking flow and success message |
